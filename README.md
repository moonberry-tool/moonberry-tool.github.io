## ✨ Why Moonberry? · ليه Moonberry؟

Designers juggle a dozen tabs just to build a brand kit — one site for colors, another for fonts,
a third for spec sheets, a fourth for inspiration prompts. **Moonberry brings all of that into a
single, fast, beautifully designed workspace**, built with a native RTL Arabic experience from
the ground up (not bolted on afterward).

المصمم عادة بيفتح 10 تابات مختلفة عشان يبني هوية بصرية واحدة — موقع للألوان، وموقع تاني للخطوط،
وثالث للمقاسات، ورابع لأفكار البرومبتات. **Moonberry بتجمع كل ده في مساحة عمل واحدة سريعة
ومصممة باحتراف**، ومبنية من الأساس عشان تدعم العربي بشكل كامل (RTL أصلي مش مُضاف لاحقًا).

## 🚀 Getting Started · التشغيل محليًا

```bash
# Clone the repository
git clone https://github.com/moonberry-tool/moonberry-tool.github.io.git
cd moonberry-tool.github.io

# Install dependencies
npm install

# Run the dev server
npm run dev
```

Then open `http://localhost:5173` in your browser. 🎉

<br/>

## 📦 Deployment · النشر

This project auto-deploys to **GitHub Pages** via GitHub Actions on every push to `main`.
The full pipeline (install → build → deploy) is defined in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

المشروع بينشر تلقائيًا على GitHub Pages من خلال GitHub Actions مع كل push على فرع `main`.
